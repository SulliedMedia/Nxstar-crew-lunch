Paste an Apps Script Web App URL here to also send every order to a Google Sheet as it's submitted. Every order already saves to this menu's built-in shared order log — this is only needed if you specifically want a Google Sheet copy for tracking.

How do I get this URL?

1. Create a Google Sheet.
2. Extensions → Apps Script, paste the doPost script your admin provided.
3. Deploy → New deployment → Web app → Execute as Me, Access: Anyone.
4. Copy the deployment URL and paste it above.
